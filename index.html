Upload directly to your repository

In GitHub, open the games folder in your hjh-gamin repository, choose Add file → Upload files, select your game, then commit the changes. Refresh this site and the game will appear automatically.

Important: This site reads files from a public GitHub repository. Anyone can view and download files in that public repository. Upload only games you own or have permission to share. GitHub is not a good host for large commercial game installers. Browser games should be self-contained .html files; downloadable games can be .zip files or other permitted file types. GitHub's browser upload limit is typically 25 MiB per file.
